# 🏨 StayFinder

StayFinder is a MERN Stack web application that allows users to browse and book hourly hotel rooms based on their needs.

---

## 🚀 Tech Stack

### Frontend
- React.js
- React Router DOM
- Axios
- Bootstrap (optional)

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
